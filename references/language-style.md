# 语言风格：节奏感 + 转场 + 标点

公文语言的核心追求：**精准、得体、有分寸**。不追求语不惊人死不休，追求读起来"顺"。

---

## 一、节奏感

材料跟音乐一样，是有节奏的。好的材料读起来不累——该快的地方快，该慢的地方慢，该喘气的地方，它给你留个空。

### 1. 长短句搭配

- **短句入题**：像戏台上"啪"地一亮相，注意力抓住
- **长句说事**：跟上几句长句，把事说透、把理讲清
- **短句收尾**：再来一句短句，像休止符，给读者喘气

> 法则：长短长短，长短短长。这叫**呼吸感**。

- 全用长句 → 读者喘不上气
- 全用短句 → 像机关枪扫射，听着有劲但听久了累，显得碎、没分量

### 2. 段落疏密

- **密段（满）**：讲工作要求，一二三四五，每条都交代清楚 → 读者打起精神看
- **松段（疏）**：紧跟着来一段过渡、一个小例子，字少 → 读者绷着的弦松下来
- **再进入密段** → 张弛有度

从头到尾都是满的密的 → 领导读着累，读完了什么也记不住。没给人留喘气、消化的空当。

### 3. 虚实交替

- **全是实的**："要""必须""坚决""确保" → 像跟人吵架，产生本能反感
- **全是虚的**："深刻领会""充分认识""切实提高" → 像念经，你到底想说什么？
- **讲问题要实**：哪个环节出问题、什么原因、数据多少 → 不能虚，一虚就显遮掩
- **讲意义可虚**：从具体事上拔起来，让人看到这事的份量 → 不是空洞，是拔高

> 虚实之间，像走路的两条腿，交替着才能往前走。

### 4. "要"字控制

"要"字是公文里最容易泛滥的字。

- 一篇不到两千字的讲话稿，七个"要" → 满嘴都是"要"，但到底要干什么，没记住
- 节制：超过 3 个就改写，换句式

### 5. 情绪节奏（轻重）

公文不讲情绪，但讲究轻重：
- **轻**：讲过去的成绩，谦虚点，别铺张
- **重**：讲当前形势，严峻性要说透
- **收**：讲下一步打算，宁可保守，别把话说满
- **分寸感**：什么时候往前赶，什么时候往后收，什么时候停下来看看

### 6. 节奏自测法

**写完了，从头读一遍。**
- 哪儿喘不上气 → 改（拆长句、加句号）
- 哪儿读着犯困 → 改（加短句提神、删废话）
- 哪儿觉得"这词儿怎么这么耳熟" → 改（换说法）
- 读到哪儿觉得"对了" → 节奏对了

## 二、转场（过渡）

### 为什么需要转场？

材料里的"转场"就是那些让文章顺滑过渡的句子。它们不负责讲具体工作，不承载核心观点，但没了它们，文章就像开车没有减震——过个坎儿能把人颠散架。

本质上是在做一件事：**给读者一个心理台阶**。你得让人家知道，为什么要从这儿走到那儿。不是硬拽，是引路。

### 转场的三种类型

**1. 逻辑转场（最常见）**

从"去年"到"今年"：
- ❌ 硬写："去年我们做了 A、B、C。今年我们打算做 D、E、F。"（这是记账）
- ✅ 有转场："回顾过去一年，A、B、C 三个项目的落地，让我们在技术储备和人才梯队上有了底气。站在这个基础上眺望新一年，我们的目光自然聚焦到了 D、E、F 这三个更前沿的领域。"

**2. 情绪转场**

从"批评"到"整改"：
- ❌ 硬写：列完一堆问题，直接接"下一步措施"
- ✅ 有转场："问题客观存在，但我们不回避、不遮掩，更不因此而气馁。相反，正视问题，恰恰是解决问题的起点。"

**3. 层次转场（搭骨架）**

从"有没有"到"好不好"：
- ✅ "如果说前者解决的是'有没有'的问题，那么后者瞄准的就是'好不好'的标准。"

### 转场的原则

- **自然第一**：转场的最高境界，是让人感觉不到转场。就像好的电影剪辑，你不会意识到"这里切了一刀"
- **不能滥用**：转场比正文还多 → 花里胡哨像迷宫，把读者转晕
- **写完检查**：从头到尾读一遍，专门看过渡的地方 → 哪儿不顺调一调 → 哪儿跳了加一句 → 哪儿啰嗦了删掉

## 三、标点符号

标点不只是"符号"，是你表达的一部分。标点用得好不好，直接反映一个人的思维水平和工作态度。

### 逗号与句号

**最常见问题：一"逗"到底**——一段话几百字，全是逗号，最后来个句号。

- 领导是扫读，不是精读
- 长句子看着就累，脑子要不停拆解结构
- **多用句号，把长句拆成短句** → 意思清爽，节奏明快
- 句号不是打断思路，是帮读者喘口气

### 冒号 vs 破折号

- **冒号**是"请看下文"——解释、说明、列举（顺承关系）
- **破折号**是"请注意"——转折、强调、突然插入（跳跃关系）

用混了 → 读者脑子里"咯噔"一下 → 材料在他心里降半格

### 引号

- **该用不用**：引用上级文件原话、领导讲话关键表述没加引号 → 分不清哪些是原文、哪些是你理解 → 态度问题，甚至可能被理解为"擅自解读"
- **不该用乱用**：动不动给某个词加引号 → 读起来总有"暗示什么"的感觉
- 引号用得好是尊重，用不好是添乱

### 感叹号与问号

不用过度拘谨，公文也可以有态度：
- **感叹号**："坚决完成任务！" vs "坚决完成任务。" → 前者有力度，后者只是陈述
- **问号**：适当用，把问题点出来，让读者跟着思路走 → 全是陈述句少了互动感

### 标点自检

- [ ] 有没有一"逗"到底的段落？
- [ ] 冒号和破折号用对了吗？
- [ ] 引号该加的都加了？不该加的都删了？
- [ ] 全角半角统一了吗？（中文引号 vs 英文引号，破折号 vs 两个减号）
- [ ] 读完一遍，标点引导的停顿对吗？

### 标点即态度

材料到了领导手里，领导从标点里读出：
- 你是不是沉得下心
- 你是不是够细致
- 你是不是对这份工作有敬畏心

标点就是你的"职业体检表"——一个连标点都敷衍的人，很难让人相信在关键处能把住关。

有些高手改材料改到最后，改的全是标点。不是在吹毛求疵，是在打磨分寸感。

## 四、去AI味的语言操作

AI写中文的根本问题：它用英文的思维方式组织中文。英文规范是精确、透明、每一步都标出来；中文的运作方式是含蓄、留白、言在此而意在彼。AI每次自动补上一个"然而"，就填掉了一个本该由读者自己走过去的空白。

### 操作1：砍连接词

AI中文最明显的特征——连接词过密。每段开头都是"然而""此外""与此同时""值得注意的是"。两句话之间明明语序已经说清了关系，AI还要加一个"因此"或"所以"。

**修复**：读完一段，把可以删掉的连接词全部删掉。中文的句子之间，很多时候不需要显性的连接词——语序本身就是逻辑。

### 操作2：拆长句

AI一句话能塞三四个从句，"由于……所以……，而这也意味着……"。要读两遍才能理清楚主语是谁、谓语在哪。

**修复**：找到可以断句的地方，用句号。一句话超过40字就检查是否该拆。

### 操作3：删掉"安全词"

AI的情绪永远不冷不热。明明在批评一件事，非要加上"当然，我们也应该看到积极的一面"。所有锋利判断都被打磨成圆角。"在某种程度上""或许""可能"——全是安全词。

**修复**：找到你的真实立场，删掉所有软化判断的"安全词"。有立场是有风险的，但同意的人会觉得"这个人说出了我想说的"。

### 操作4：恢复"人在说话"的感觉

AI文章读完后感觉不到背后站着一个具体的人。没有"说实话""其实""怎么说呢"这类表达，没有语气词（吧、呢、啊、嘛），每句话都是完整的陈述句。

**修复**（仅适用于讲话稿、汇报等口语化文种）：
- 适当加入口语化表达：说实话、说到底、讲真的
- 适当使用语气词：吧、呢、啊、嘛
- 允许不完整的句子存在：话说一半，留一半给读者
- 注意：正式报告、请示等法定公文不适用此条

### 操作5：结尾停在画面上，不要总结

AI的结尾一定要总结——"综上所述""总的来说""这给我们带来了深刻的启示"。好像不加这么一段，文章就没有结束似的。

**修复**：试着让结尾停在一个具体的画面上、一个未尽的思考上、一个行动的号召上。不是每篇文章都需要"总结"。

### 语言自检：这稿子像人写的吗？

- [ ] 从头到尾读一遍，有没有"翻译腔"？（像从英文翻译过来的）
- [ ] 连接词能删的都删了吗？
- [ ] 有没有超过40字还在跑的句子？
- [ ] 有没有"在某种程度上""或许""可能"这类安全词？
- [ ] 读完之后，能想象出"谁"在说话吗？
- [ ] 结尾是不是停在了一个有力量的地方，而不是"综上所述"？

### 核心认知

不是AI"写不好中文"，是中文的运作方式和AI的默认模式根本冲突。AI把那些空白都填上了——填得很认真，很工整，很专业。但中文的灵魂，恰恰住在那些空白里。去AI味不是润色，是**还原**：把那些不属于中文的东西摘掉，让中文用自己的方式说话。
