# 公文精简三法则：从"逸马杀犬于道"说起

> 欧阳修用六个字说清一件事。公文不是不能写长，是"能短则短"——领导的注意力，就是公文最稀缺的资源。

## 一、典故：欧阳修的六字改文

欧阳修和同僚散步，一匹奔马踩死了一条狗。他让大家把这件事写下来，看谁最简练。

| 版本 | 原文 | 字数 |
|------|------|------|
| 同僚A | "有犬卧于通衢，逸马蹄而杀之" | 12字 |
| 同僚B | "有马逸于街衢，卧犬遭之而毙" | 12字 |
| **欧阳修** | **"逸马杀犬于道"** | **6字** |

字数减半，信息一字不差。欧阳修说完，补了一句让所有人沉默的话："如果让你们编修史书，按你们的写法，一万卷都不够写。"

欧阳修当过翰林学士，负责起草朝廷诏书。他深知——**公文越长，执行的人越看不懂，越不想执行。**

## 二、三条精简法则

### 法则一：删除"重复表述"

同僚写"有犬卧于通衢"——"卧"已经是状态，"于通衢"是地点。欧阳修连"卧"都不要了："杀犬于道"——谁杀、杀谁、在哪杀，三要素齐了。

**应用：** 删掉所有只起修饰作用、不增加信息量的定语和状语。你的公文里有多少"众所周知""毋庸置疑""显而易见"？这类词全部删除，信息量丝毫不少。

**公文自检：**
- "全面深入的调查研究" → "调研"
- "积极稳妥地推进各项工作" → "推进"（推进本身就包含态度）
- "在上级部门的正确领导下" → 删（这句话放在任何一篇都成立 = 信息量为零）

### 法则二：把"过程描述"压缩成"结果陈述"

同僚写"逸马蹄而杀之"——描述了"用蹄子踩"这个动作。欧阳修写"逸马杀犬"——谁、做什么、对谁做，三要素打包。没必要描述"怎么杀的"。

**应用：**
- "通过召开会议、听取汇报、实地走访等方式，进行了调查研究" → "经调研"
- "针对上述问题，组织相关人员进行了深入的分析和研判" → "经分析研判"
- "按照年初制定的工作计划，有序推进了各项目标任务的落实" → 直接写做了什么、做到了什么程度

**核心原则：过程不重要，结果才重要。** 领导不需要知道你怎么调研的，他需要知道你调研出了什么。

### 法则三：所有的"修饰"都是敌人

同僚用了"通衢"（大路），文雅，但信息量和"道"完全一样。两个字缩成一个字。

**应用：**
- "进行了一次全面深入的分析" → "经分析"
- "取得了十分显著的成效" → "成效为：……"（后面直接跟数据）
- "为……作出了积极贡献" → 删（做了什么事自己会说，不用你替它说）

**领导没时间欣赏你的文采。** 公文的修饰词有三个功能：凑字数、显文采、掩盖内容空泛。三个功能都是致命的。

## 三、"能短则短"的自检方法

写完每一段，过三刀：

**第一刀：删掉这句，信息有损失吗？**
没有 → 整句删掉。有 → 保留。

**第二刀：能不能用更少的字说清楚？**
能 → 改写。比如"对某项工作进行研究部署"→"研究部署某项工作"。

**第三刀：剩下的修饰词，每个都经得起追问吗？**
"全面""系统""深入""扎实"——每一项都能在后面找到对应的具体内容吗？不能 → 删。

## 四、精简≠简陋

精简不是让你把内容砍到只剩骨架。缩字数是手段，提纯信息密度才是目的。欧阳修六个字和三要素的对应：

| 要素 | 对应字 | 今天公文的对标 |
|------|--------|-------------|
| 谁 | "逸马" | 责任主体 |
| 做了什么 | "杀" | 核心动作 |
| 对象/结果 | "犬" | 工作对象/达成效果 |
| 在哪/什么范围 | "于道" | 范围/场景限定 |

**公文的终极标准：** 每一句话都必须包含"**谁/什么 + 做了什么 + 结果如何**"。如果删掉某一句话不影响读者理解，那就删掉它。用最短的字数，传达最全的信息。

## 五、适合"瘦身"的高频场景

- **工作总结**：删掉所有"在……下""取得了""实现了"的句式赘肉，直接写数据+做法
- **简报信息**：三句话说不清的事，不是信息量太大，是没想清楚
- **PPT/汇报提纲**：每页最多一个判断+三个支撑数据
- **微信/邮件汇报**：先写结论，再写理由，不写过程

说一句算一句，句句不空。这就是公文的终极标准。
