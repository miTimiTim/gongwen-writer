# 公文格式规范

生成 .docx 文件时严格遵循以下格式。本规范参照《党政机关公文格式》（GB/T 9704）并结合国企常用排版惯例制定。

## 一、页面设置

| 项目 | 数值 |
|------|------|
| 上页边距 | 3.7 cm |
| 下页边距 | 2.5 cm |
| 左页边距 | 2.7 cm |
| 右页边距 | 2.6 cm |
| 行距 | 固定值 29 磅 |
| 页码 | 不加页码 |

## 二、字体字号

| 元素 | 字体 | 字号 | 加粗 | 对齐 |
|------|------|------|------|------|
| 方案题目（大标题） | 方正小标宋简体 | 二号（22pt） | 否 | 居中 |
| 一级标题（一、二、三…） | 黑体 | 三号（16pt） | **是** | 两端对齐 |
| 二级标题（（一）（二）…） | 黑体 | 三号（16pt） | **是** | 两端对齐 |
| 三级标题（1. 2. 3.…） | 仿宋 | 三号（16pt） | **是** | 两端对齐 |
| 正文 | 仿宋 | 三号（16pt） | 否 | 两端对齐 |
| 表格内文字 | 仿宋 | 四号（14pt） | 否 | 视情况 |
| 表头文字 | 黑体 | 四号（14pt） | **是** | 居中 |

## 三、标题编号规则

采用"一、（一）、1."三级编号体系，与正文格式对应：

```
一、XXXX（一级标题，黑体三号加粗）
  （一）XXXX（二级标题，黑体三号加粗）
    1. XXXX（三级标题，仿宋三号加粗）
    2. XXXX
  （二）XXXX
二、XXXX
```

## 四、段落格式

- **首行缩进**：正文段落首行缩进 2 字符（32pt）
- **标题不缩进**：各级标题顶格，不设首行缩进
- **方案题目**：大标题居中，与正文之间空一行
- 如标题为两行（如"公司名称"一行 + "方案名称"一行），两行均居中，字号相同

## 五、特殊格式说明

### 表格
- 表格内文字四号（14pt），表头黑体加粗居中，内容仿宋
- 表格左右对齐页面正文边界
- 表格前后各留一行空行

### 引号规范
- 引用上级文件名称、领导讲话原文、特定表述时加引号
- 使用中文全角引号——""
- 不使用英文引号 ""

### 数字用法
- 公历世纪、年代、年、月、日使用阿拉伯数字
- 统计数字、物理量、百分比使用阿拉伯数字
- 一般性叙述中的数字，如非精确值，可用汉字

## 六、Python 实现要点

使用 python-docx 库时：

```python
from docx.shared import Pt, Cm
from docx.enum.text import WD_ALIGN_PARAGRAPH

# 页边距
section.top_margin = Cm(3.7)
section.bottom_margin = Cm(2.5)
section.left_margin = Cm(2.7)
section.right_margin = Cm(2.6)

# 行距固定 29 磅
pf.line_spacing = Pt(29)
# 需在 XML 层设置 lineRule 为 exact

# 中文字体需同时在 rFonts 中设置 eastAsia 属性
rFonts.set(qn('w:eastAsia'), '仿宋')
```

## 七、字体缺失时的降级方案

如用户电脑未安装指定字体，按以下顺序降级：

| 指定字体 | 降级顺序 |
|---------|---------|
| 方正小标宋简体 | 华文中宋 → 宋体 |
| 黑体 | 微软雅黑加粗 → 宋体加粗 |
| 仿宋 | 仿宋_GB2312 → 宋体 |
