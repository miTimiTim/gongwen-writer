# 日常积累：平时出力，战时出彩

写材料的人真正的核心竞争力，不在动笔那几小时，而在不动笔的那几百小时。平时攒下的东西，战时会一件一件还给你。

---

## 一、先认清自己在哪个层次

写材料有三个层次，知道自己在哪一层，才知道该往哪使劲：

| 层次 | 在做什么 | 状态 |
|------|---------|------|
| 词句层 | 琢磨用什么词、怎么造句 | 纠结"写得像不像" |
| 框架层 | 搭结构、理关系、排顺序 | 关注"逻辑顺不顺" |
| 思想层 | 提炼观点、判断形势、洞察本质 | 思考"这事到底意味着什么" |

大多数人困在词句层出不来。不是因为懒，是因为没有往上走的路。日常积累，就是修路。

---

## 二、五字诀：要 搜 读 合 练

### 1. 要 — 掌握情况（做法 + 效果）

"要"是主动获取，不是被动接收。从四个维度做好储备：

| 维度 | 要点 | 目的 |
|------|------|------|
| **向上要** | 各级重要讲话、批示、指示精神 | 让文稿有**高度** |
| **向下要** | 基层可复制可传播的亮点做法 | 让文稿有**温度** |
| **向内要** | 本单位历史沿革、当前现状、下步举措 | 让文稿有**厚度** |
| **向外要** | 兄弟地区和单位的经验做法 | 让文稿有**广度** |

特别注意"要"现成的重要会事材料——会事规格越高，材料质量越好，数据准确、进展翔实、措施具体，堪称阶段性工作的集大成者。既可以学业务最新进展，也可学文稿体例和领导意图。

---

### 2. 搜 — 有效储备

"搜"不是随手收藏，是成体系地储备。核心原则：**以我为主、为我所用**。

舍得花精力去读、去分类、去精细储备。不是为了收藏数字好看，是为了战时能用。

---

### 3. 读 — 静心深阅读，注重实际占有

高水平写作的实质，是写手的信息占有量和信息处理能力。最高标准是**内容为王**——在简洁篇幅中传输更多有效、有价值、有深度的信息。

#### 泛读

带着平时思考的问题，扫描式浏览，迅速看标题、导语、段首、内容。判断是否值得精读，判断依据——
- 谋篇布局有无借鉴价值？
- 段落结构有无借鉴价值？
- 字词语句有无借鉴价值？

#### 精读三部曲

**第一步：扫导语，找准文章主题。** 领导讲话稿通常是开门见山亮明主题。精读第一步是快速找准主题，明确文章要解决什么问题。

**第二步：扫一级标题，研究文章逻辑架构。** 带着问题阅读——在确定主题的前提下，研究文章各部分如何为主题服务，文章的整体思路是什么。按公文核心逻辑（是什么—为什么—怎么办）推测文章会重点阐述什么。

**第三步：逐字逐句精读，前后反复对照。** 琢磨这几样东西——
- 标题提炼的艺术
- 起承转合的奥妙
- 一级小标题如何服务于文章主题，各级小标题如何服务于上级标题
- 文中的好观点好词句

做好标记、批注、摘录，留备下次使用和研究。

"是什么、为什么、怎么办"是公文写作最核心的论述逻辑。在精读中多带着这三个问题去体会它们在不同文章中的多样性体现。有时三者相互交织，你中有我、我中有你。要从这个核心逻辑出发，分析文章的文脉和技法，把佳作的写作思维、理念、语句固化下来。

---

### 4. 合 — 分类萃与合，随时揣摩备用

分类的实质是建构——将复杂事物拆解重组，按一定的认知逻辑重新搭建体系。

#### 方法一：按业务分类

参考国务院官网"政策"栏目的文件库分类（共 22 种）：综合政务、国民经济管理、财政金融审计、国土资源能源、农业林业水利、工业交通、商贸海关旅游、市场监管安全生产、城乡建设环境保护、科技教育、文化广电新闻出版、卫生体育、劳动人事监察、公安安全司法、民政扶贫救灾等。

根据自身岗位，建立自己的业务分类体系。

#### 方法二：按词句、功能套件分类

按 11 个专题组织素材库：

| 专题 | 内容 |
|------|------|
| 第一专题 | 大手笔们关于写材料的心得体会 |
| 第二专题 | 分类词句（最新修订的词句，拟标题时发散思维用） |
| 第三专题 | 提纲标题（各类特色亮点小标题范例） |
| 第四专题 | 文稿分类技巧、范例及剖析（讲话稿、总结、汇报、信息、调研报告、纪要、工作报告等） |
| 第五专题 | 功能套件（开头、结尾、成果、问题、措施等常用套件范例） |
| 第六专题 | 综合稿分类内容 |
| 第七专题 | 党建稿分类内容 |
| 第八专题 | 基本功锤炼（素材储备、读什么怎么读、写作逻辑） |
| 第九专题 | 经典系列专题研究分析 |
| 第十专题 | 典籍素材（提升文章历史厚度） |
| 第十一专题 | 智能查询 |

#### 方法三：按方法分类

按工作开展逻辑进行词句分类。各类材料的共性方法论维度：成果类、领导类、形势类、调研类、群众类、谋划类、落实类、措施类、状态类、奋斗类、担当类、推进类、组织类、责任类、重点类、问题类、难点类、精准类、学习类、效率类、信念类、廉洁类、治党类、督查类、改革类、创新类、团结类、宣传类等。

#### 方法四：按功能分类

**降维打击法**：用高规格材料打击低规格材料——
- 政府工作报告 → 打击政务信息、工作汇报、工作总结、民主生活会发言、理论中心组发言、党课发言等

按各级党代会报告 + 政府工作报告分类整理功能套件，共十类：主题、一级标题、成果标题、经验体会、存在问题、总体要求、预期目标、措施类小标题、各部分开头导语、末尾。

---

### 5. 练 — 沙场秋点兵，实战靶向储备

"练"是通过一次次小练兵，搭建更高一级的储备——模板，达到战时有备无患。

平时要有意识留意有价值的主题，提炼成随时能用的模板。推荐建立三类模板：

**① 重要工作进展模板**
```
最新进展情况及做法 → 存在问题及下步措施 → 意见建议
```

**② 重要数据模板**
养成收集数据、汇总数据、研究数据的习惯。重点关注四类数据：
- 领导普遍关切的
- 社会舆论高度关注的
- 重要材料经常出现的
- 年度指标任务具体涵盖的

**③ 自主选题的理论段落模板**
按"为什么—是什么—怎么办"的核心逻辑，自己写小段落、小文章，以备随时套改。

---

## 三、积累的本质

日常积累不是做资料搬运工，是**把你的脑子变成一个可随时调用的搜索引擎**。

- **要**是获取原料
- **搜**是建索引
- **读**是消化吸收
- **合**是结构化存储
- **练**是实战提取

五步做扎实了，战时才能"提笔就写，写就到位"。

---

## 四、积累自检

- [ ] 平时有没有固定的"要"的习惯？（上级文件、基层亮点、兄弟单位经验）
- [ ] 读好材料时有没有做批注、摘录的习惯？
- [ ] 有没有自己的分类体系？（按业务 / 按方法 / 按功能至少有一套）
- [ ] 有没有建立自己的模板库？（工作进展模板 / 数据模板 / 理论段落模板）
- [ ] 最近一个月有没有主动"练"过？（哪怕只是写一段自主选题的段落）
