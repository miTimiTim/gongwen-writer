# 文种规范与选用

## 一、法定公文（15 种）

根据《党政机关公文处理工作条例》，法定公文共 15 种。这里列出最常用的 8 种：

### 1. 报告
- **用途**：向上级汇报工作、反映情况、回复询问
- **特点**：陈述性，不要求批复
- **常见场景**：年度工作报告、专项工作报告、调研报告
- **结构模板**：背景/依据 → 主要工作/情况 → 存在问题 → 下一步打算
- **关键**：数据准确、分析深入、建议可行

### 2. 请示
- **用途**：向上级请求指示、批准
- **特点**：一文一事，必须提前请示
- **常见场景**：申请经费、申请项目立项、请求政策解释
- **结构模板**：请示缘由（为什么） → 请示事项（要什么） → 可行性与预期效益
- **关键**：理由要充分，方案要清晰，不能"先斩后奏"

### 3. 通知
- **用途**：发布、传达要求下级执行或有关单位周知的事项
- **特点**：下行文，具有约束力
- **常见场景**：会议通知、工作部署通知、人事任免通知
- **结构模板**：依据/目的 → 通知事项（分条列项） → 执行要求 + 时间节点
- **关键**：事项写清楚，要求写明确，时间写死

### 4. 函
- **用途**：不相隶属机关之间商洽工作、询问和答复问题
- **特点**：平行文，平等协商的语气
- **常见场景**：征求意见、商洽合作、回复问询
- **结构模板**：致函缘由 → 具体事项 → 期望回复的方式和时间
- **关键**：语气平等尊重，不命令不卑微

### 5. 纪要
- **用途**：记载会议主要情况和议定事项
- **特点**：客观记录，不展开论述
- **常见场景**：党组会纪要、专题会纪要、协调会纪要
- **结构模板**：会议基本信息 → 议定事项（分条） → 参会人员/时间
- **关键**：只记议定事项，不记讨论过程

### 6. 通报
- **用途**：表彰先进、批评错误、传达重要精神或情况
- **特点**：典型性和教育性
- **常见场景**：表彰通报、批评通报、情况通报
- **结构模板**：被通报事项 → 分析评价 → 表彰/批评决定 → 希望和要求

### 7. 批复
- **用途**：答复下级机关请示事项
- **特点**：针对性强，有来才有往
- **结构模板**：引述来文 → 表态（同意/不同意/部分同意） → 补充要求

### 8. 决定
- **用途**：对重要事项作出决策和部署
- **特点**：权威性、约束性强
- **常见场景**：表彰决定、处分决定、重大部署决定

## 二、常用事务文书（非法定但高频）

### 1. 工作总结
- **用途**：回顾一段时期的工作，总结成绩和不足
- **核心逻辑**：面临什么困难 → 做了什么 → 取得了什么突破
- **三段式**：成绩 → 不足 → 打算
- **注意**：困难写小了→成绩不值钱；困难写大了→显得无能。度要拿捏

### 2. 讲话稿
- **用途**：领导在会议、活动上的发言
- **特点**：口语化但不能随意，有态度、有温度、有节奏
- **读者意识**：台下的人想听什么？听完能记住什么？
- **节奏要求**：长短句搭配，有高潮有舒缓，该停顿的地方停

### 3. 工作方案
- **用途**：对某项工作作出全面安排
- **核心要素**：目标、任务、措施、时间节点、责任分工、保障机制
- **结构**：总体要求 → 重点任务 → 实施步骤 → 组织保障

### 4. 调研报告
- **用途**：通过调研发现问题、分析原因、提出建议
- **核心逻辑**：现象描述 → 原因分析 → 对策建议
- **站位要求**：小切口深挖掘，从具体的人/事出发，上升到制度层面

### 5. 汇报材料
- **用途**：口头汇报的书面底稿（PPT 配套或向上级口头汇报）
- **特点**：精炼、要点突出、留白（给领导提问空间）
- **短剧思维**：开门见山亮观点，每段有结论

### 6. 述职报告
- **用途**：个人/班子向组织和群众报告履职情况
- **结构**：履职情况 → 存在问题 → 努力方向
- **注意**：成绩不夸大，问题不回避，跟岗位职责对得上

## 三、文种选用决策树

```
写给谁？
├── 上级
│   ├── 需要批复？→ 请示
│   ├── 汇报工作/反映情况？→ 报告
│   └── 会议发言？→ 讲话稿
├── 平级
│   └── 商洽/询问/答复？→ 函
├── 下级
│   ├── 传达部署？→ 通知
│   ├── 表彰/批评？→ 通报
│   └── 答复请示？→ 批复
└── 自己留存/复盘
    ├── 回顾一段时期？→ 工作总结
    ├── 深入分析问题？→ 调研报告
    └── 会议记录？→ 纪要
```
