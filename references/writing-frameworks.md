# 框架搭建：搞关系 + 材料逻辑

## 一、核心思想：框架就是"搞关系"

写材料搭框架，说到底就是搞清楚材料里所有内容的"来龙去脉"——每句话、每个段落彼此之间到底是什么关系。

不是拉人情走后门的那种"搞关系"，是把逻辑关系理清楚。

### 1. 先搞懂核心关系（材料逻辑三层）

**第一层：用户思维**
- 写材料不是写日记，也不是写论文
- 读者是领导、上级、那个要看你材料拍板的人
- 问自己：他看这篇材料最关心什么？
- 怎么让对方舒服地理解你想让他知道的东西

**第二层：问题导向**
- 一篇材料最硬的逻辑：它到底要解决什么问题？
- 申请经费 → "为什么给钱—钱花在哪—花完有啥好处"
- 总结成绩 → "面临什么困难—做了什么—取得什么突破"
- 反思问题 → 先肯定再反思（"虽取得成绩，但对照更高要求…"）

**第三层：站位逻辑**
- 你代表谁在说话？
- 代表科室："我们建议增加人手"
- 代表全局："通过优化内部调配和争取外部支持，多措并举解决人力瓶颈"
- 前者是诉求，后者是方案

### 2. 再搞清内部小关系

几个部分之间是什么关系？
- **并列** → 每个要点权重差不多，按维度分（政治/经济/文化…）或按部门分
- **递进** → 一步步深入，从基础到重点、从做法到成效，不能颠倒
- **主次** → 总有核心观点和支撑论据，核心放显眼位置，重点多着墨

## 二、七大经典框架

### 1. 三段式（最常用）
```
现状/成绩 → 问题/不足 → 建议/打算
```
- 适合：工作报告、工作总结、调研报告
- 要点：三段权重不是 1:1:1，按目的调整。总结成绩为主→成绩 60%，反思为主→问题 50%
- 变体：背景→做法→成效；困难→对策→启示

### 2. 总分总
```
总述（结论先行） → 分述（逐条展开） → 总结（升华回扣）
```
- 适合：讲话稿、汇报材料、分析报告
- 要点：开头就亮出核心观点，不要让读者猜

### 3. 金字塔原理
```
核心结论
├── 一级论点 A
│   ├── 论据 A1
│   └── 论据 A2
├── 一级论点 B
└── 一级论点 C
```
- MECE 原则：相互独立、完全穷尽
- 结论先行、以上统下

### 4. 5W1H
```
What（什么事） → Why（为什么） → Who（谁负责）
→ When（什么时间） → Where（在哪里） → How（怎么做）
```
- 适合：工作方案、部署通知
- 确保信息完整无遗漏

### 5. 因果链
```
现象 → 直接原因 → 深层原因 → 根本原因 → 对策
```
- 适合：分析报告、问题剖析材料
- 每往下一层，就问一个"为什么"
- 追问至少 3 层才能触及本质

### 6. SWOT
```
优势（Strengths） + 劣势（Weaknesses）
机会（Opportunities） + 威胁（Threats）
→ 交叉得出战略选择
```
- 适合：战略分析、形势研判
- 不是罗列，是交叉分析（SO/WO/ST/WT）

### 7. 对比法
```
时间对比（同比/环比） + 空间对比（地区/渠道）
+ 标杆对比（行业/竞品） + 目标对比（实际 vs 计划）
```
- 适合：分析报告、经济运行分析
- 对比后必须追问"为什么有差异"

## 三、框架搭建实操四步

**Step 1：定方向（核心关系）**
- 这篇材料给谁看？想达到什么目的？
- 一句话写出"这篇材料的核心任务"

**Step 2：列清单**
- 把想写的内容全部列出来（先别管顺序）
- 每一条控制在 10 字以内

**Step 3：理关系（内部小关系）**
- 对着清单问：A 和 B 是什么关系？并列还是递进？谁先谁后？谁重谁轻？
- 问来问去，关系就理顺了

**Step 4：出提纲**
- 理顺后输出三级标题
- 按"标题四来源"逐一打磨标题措辞

## 四、框架自检清单

- [ ] 读者拿到这份材料，3 秒内能知道要说哪几件事吗？
- [ ] 各部分之间是并列、递进还是主次？关系对吗？
- [ ] 有没有明显遗漏的部分？（MECE 检视）
- [ ] 是否有部分权重失衡？（该重的不重，该轻的不轻）
- [ ] 框架是为"解决问题"服务的，还是为"看起来好看"服务的？

## 五、结构类型选择：块状 vs 条状

材料结构分两种基本形态，可灵活融合：

- **块状结构**：适合内容庞杂的总结报告、调研报告。按主题分块，每块内部自成体系。优势是覆盖面广，逻辑层次分明。
- **条状结构**：适合观点鲜明的讲话稿、汇报材料。按论点逐条推进，一条一个观点。优势是聚焦、有力、好记。

选择原则：内容多而杂 → 块状；观点少而精 → 条状。两种结构可在同一篇材料中融合——大框架用块状，每块内部用条状展开。

## 六、框架思维培养

框架不是谁发明的，是从实践中总结出来的规律。写材料的人，真正的核心竞争力不是文采，是框架思维。

### 为什么框架比文采重要？

句子再美，逻辑一乱，整篇作废。结构一散，篇幅越长越露馅。框架是骨骼，文采是血肉——骨骼立住了，血肉才有地方依附。

### 框架的本质

框架不是"一二三""首先其次最后"。框架的本质是**逻辑**，是对事物规律的理解和提炼：

- 写工作方案 → 背景 → 目标 → 举措 → 保障
- 写总结报告 → 做法 → 成效 → 问题 → 打算
- 写领导讲话 → 成绩 → 问题 → 部署
- 做任何一件大事 → 宣传动员 → 领导小组 → 科学决策 → 宏观规划 → 项目建设 → 资金筹划 → 组织保障 → 分步实施

### 怎么练出框架能力？

1. **积累：建自己的"框架库"** — 把写过的方案、报告、总结分类整理。每一个框架为什么有效？能不能迁移到下一个材料里？
2. **提炼：从具体工作中抽象规律** — 不要只埋头写，要抬头思考。这个工作的核心矛盾是什么？解决的路径是什么？有没有普遍性？
3. **复盘：写完材料回头看** — 这个框架为什么有效？下次还能怎么优化？有没有更好的排列组合？

### 提纲定级原则

- 提纲定到三级，便能胸有成竹
- 新手可细化至四五级，做到腹中有稿
- 起草前切忌匆忙下笔、堆砌资料、平均用力——花时间打磨框架，是最值得的投资
