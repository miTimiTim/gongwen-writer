# 框架搭建：搞关系 + 材料逻辑

## 零、公文的第一性原理：问题导向

在学框架之前，先问一个更根本的问题：这份材料到底要解决什么问题？

没有问题意识的文稿，就像没有靶心的箭矢，射得再远也是虚发。篇篇都在谈"提高认识""加强领导""狠抓落实"，却对具体工作中到底存在什么困难、是什么原因造成的、如何针对性破解，语焉不详、一笔带过——这样的文稿既无法指导实践，也无法回应群众关切，最终只会消耗公文的公信力和权威性。

公文何以为"公"？它是组织意志的表达，是推动工作的工具。而推动工作的内在逻辑，恰恰是**发现问题、分析问题、解决问题**。问题导向不是一种可选技巧，而是公文的根本属性和内在要求。离开问题，公文就失去了存在的意义；回避问题，公文就会沦为纸上谈兵。

### 好公文从来都是奔着问题去的

每一篇真正有分量的文稿，必然以真问题为内核、以深入分析为骨架、以务实对策为血肉。动笔之前，先回答三个问题：

1. **这份材料要解决什么问题？** —— 如果回答不出来，先别动笔
2. **存在哪些突出矛盾？** —— 不是泛泛的"发展质量不高"，而是具体的：产业结构单一？创新能力不足？营商环境不优？哪一个才是真正卡脖子的？
3. **受众最关心什么？** —— 上级关心的是风险还是机遇？下级关心的是资源还是方向？

### 什么样的问题是"真问题"

一篇文稿篇幅有限，必须着力于抓住真问题。三条标准：

1. **紧扣主题。** 越是关键问题，与文稿主旨的关系越紧密。离开主题谈问题，多数是假问题。
2. **切中实际。** 真问题来自一线、来自实践。坐在办公室里"想"出来的问题，往往是脱离实际的伪问题。没有调查研究，就没有发言权。
3. **具备解决可能。** 公文是推动工作的工具，问题的提出最终要服务于解决方案。如果一个问题提出后也无法解决，那就不是一篇公文应着力讨论的对象——那可能是学术研究或内参的范畴。

### 以问题贯穿全文

一篇好的公文，"问题主线"应贯穿始终。基本框架遵循"发现问题—分析问题—解决问题"的逻辑链条：

- **发现问题是前提**：敢于正视问题，不"报喜不报忧"。敢于直面问题恰恰是自信的表现，也最能赢得受众的尊重。
- **分析问题是关键**：弄清成因、性质和内在联系，区分主要矛盾和次要矛盾，抓住症结所在——这是文稿能否写深写透的决定性因素。
- **解决问题是归宿**：公文的全部价值，最终要体现在能否推动问题解决上。对策要"对症下药"——既符合政策又切合实际，既有针对性又有可行性。

### 问题意识的日常修炼

- 面对看似"正常"的现象，多问几个"为什么"
- 面对看似"合理"的安排，多问几个"是否还有更好的办法"
- 把每一次写稿当成一次研究：既研究怎么写，更研究这事到底是什么问题
- 写完自检：这篇材料里提出的问题，是"老生常谈式"的隔靴搔痒，还是真正切中了要害？

没有问题，才是公文写作最大的问题。只有始终以问题为导向，公文才能回归"以文辅政"的本源。

## 一、核心思想：框架就是"搞关系"

写材料搭框架，说到底就是搞清楚材料里所有内容的"来龙去脉"——每句话、每个段落彼此之间到底是什么关系。

不是拉人情走后门的那种"搞关系"，是把逻辑关系理清楚。

### 1. 先搞懂核心关系（材料逻辑三层）

**第一层：用户思维**
- 写材料不是写日记，也不是写论文
- 读者是领导、上级、那个要看你材料拍板的人
- 问自己：他看这篇材料最关心什么？
- 怎么让对方舒服地理解你想让他知道的东西

**第二层：问题导向**
- 一篇材料最硬的逻辑：它到底要解决什么问题？
- 申请经费 → "为什么给钱—钱花在哪—花完有啥好处"
- 总结成绩 → "面临什么困难—做了什么—取得什么突破"
- 反思问题 → 先肯定再反思（"虽取得成绩，但对照更高要求…"）

**第三层：站位逻辑**
- 你代表谁在说话？
- 代表科室："我们建议增加人手"
- 代表全局："通过优化内部调配和争取外部支持，多措并举解决人力瓶颈"
- 前者是诉求，后者是方案

### 2. 再搞清内部小关系

几个部分之间是什么关系？
- **并列** → 每个要点权重差不多，按维度分（政治/经济/文化…）或按部门分
- **递进** → 一步步深入，从基础到重点、从做法到成效，不能颠倒
- **主次** → 总有核心观点和支撑论据，核心放显眼位置，重点多着墨

## 二、七大经典框架

### 1. 三段式（最常用）
```
现状/成绩 → 问题/不足 → 建议/打算
```
- 适合：工作报告、工作总结、调研报告
- 要点：三段权重不是 1:1:1，按目的调整。总结成绩为主→成绩 60~70%，问题 15~20%，打算 15~20%；反思为主→问题 50%
- 成绩段火候：有面有点——面上概括全局，点上用典型案例支撑，呈现的是治理能力而非忙碌程度
- 问题段火候：写"共性不足"而非"个性失误"，归因于客观制约与能力短板的结合，既体现问题意识又把握分寸
- 打算段火候：必须逐一回应前面提出的问题，让上级看到"知道短板在哪，也有改进的思路"
- 变体：背景→做法→成效；困难→对策→启示

### 2. 总分总
```
总述（结论先行） → 分述（逐条展开） → 总结（升华回扣）
```
- 适合：讲话稿、汇报材料、分析报告
- 要点：开头就亮出核心观点，不要让读者猜

### 3. 金字塔原理
```
核心结论
├── 一级论点 A
│   ├── 论据 A1
│   └── 论据 A2
├── 一级论点 B
└── 一级论点 C
```
- MECE 原则：相互独立、完全穷尽
- 结论先行、以上统下

### 4. 5W1H
```
What（什么事） → Why（为什么） → Who（谁负责）
→ When（什么时间） → Where（在哪里） → How（怎么做）
```
- 适合：工作方案、部署通知
- 确保信息完整无遗漏

### 5. 因果链
```
现象 → 直接原因 → 深层原因 → 根本原因 → 对策
```
- 适合：分析报告、问题剖析材料
- 每往下一层，就问一个"为什么"
- 追问至少 3 层才能触及本质

### 6. SWOT
```
优势（Strengths） + 劣势（Weaknesses）
机会（Opportunities） + 威胁（Threats）
→ 交叉得出战略选择
```
- 适合：战略分析、形势研判
- 不是罗列，是交叉分析（SO/WO/ST/WT）

### 7. 对比法
```
时间对比（同比/环比） + 空间对比（地区/渠道）
+ 标杆对比（行业/竞品） + 目标对比（实际 vs 计划）
```
- 适合：分析报告、经济运行分析
- 对比后必须追问"为什么有差异"

### 8. 先立后破
```
立（正面阐述） → 破（分析问题） → 合（提出路径）
```
- 适合：讲话稿、分析报告、评论文章
- 要点：
  - **立**：开篇先正面阐述正确的观点、成就、必要性，建立认同基础
  - **破**：分析当前存在的问题、错误认识、面临的阻碍，制造论述张力
  - **合**：提出解决问题的路径、方法，升华意义，完成逻辑闭环
- 关键：立和破之间必须有顺畅的逻辑过渡。比如"成绩固然可喜，但我们也要清醒地看到……"，转折自然流畅不生硬
- 避免"结构断层"——立讲完了直接跳到破，读者脑子里的"为什么突然说这个"就是断层信号

### 9. 三阶递进式
```
事实 → 观点 → 升华
```
- 适合：讲话稿、汇报材料、评论文章
- 要点：
  - **第一阶·摆事实**：以一个或一组客观、典型的事实/故事开篇，吸引读者——这是"融意于述"的起点
  - **第二阶·亮观点**：从事实中自然提炼出核心观点，进行逻辑论证。前文的事实铺垫让论证更有说服力
  - **第三阶·大升华**：将具体论点上升到更普遍的意义、更宏大的价值层面（如从一个企业的故事升到整个行业的信心问题）
- 核心效果：让读者在不知不觉中，跟随叙事逻辑走向预设的结论，实现"在打动人中说服人"

## 三、框架搭建实操四步

**Step 1：定方向（核心关系）**
- 这篇材料给谁看？想达到什么目的？
- 一句话写出"这篇材料的核心任务"

**Step 2：列清单**
- 把想写的内容全部列出来（先别管顺序）
- 每一条控制在 10 字以内

**Step 3：理关系（内部小关系）**
- 对着清单问：A 和 B 是什么关系？并列还是递进？谁先谁后？谁重谁轻？
- 问来问去，关系就理顺了

**Step 4：出提纲**
- 理顺后输出三级标题
- 按"标题四来源"逐一打磨标题措辞

## 四、框架自检清单

- [ ] 读者拿到这份材料，3 秒内能知道要说哪几件事吗？
- [ ] 各部分之间是并列、递进还是主次？关系对吗？
- [ ] 有没有明显遗漏的部分？（MECE 检视）
- [ ] 是否有部分权重失衡？（该重的不重，该轻的不轻）
- [ ] 框架是为"解决问题"服务的，还是为"看起来好看"服务的？

## 五、结构类型选择：块状 vs 条状

材料结构分两种基本形态，可灵活融合：

- **块状结构**：适合内容庞杂的总结报告、调研报告。按主题分块，每块内部自成体系。优势是覆盖面广，逻辑层次分明。
- **条状结构**：适合观点鲜明的讲话稿、汇报材料。按论点逐条推进，一条一个观点。优势是聚焦、有力、好记。

选择原则：内容多而杂 → 块状；观点少而精 → 条状。两种结构可在同一篇材料中融合——大框架用块状，每块内部用条状展开。

## 六、框架思维培养

框架不是谁发明的，是从实践中总结出来的规律。写材料的人，真正的核心竞争力不是文采，是框架思维。

### 为什么框架比文采重要？

句子再美，逻辑一乱，整篇作废。结构一散，篇幅越长越露馅。框架是骨骼，文采是血肉——骨骼立住了，血肉才有地方依附。

### 框架的本质

框架不是"一二三""首先其次最后"。框架的本质是**逻辑**，是对事物规律的理解和提炼：

- 写工作方案 → 背景 → 目标 → 举措 → 保障
- 写总结报告 → 做法 → 成效 → 问题 → 打算
- 写领导讲话 → 成绩 → 问题 → 部署
- 做任何一件大事 → 宣传动员 → 领导小组 → 科学决策 → 宏观规划 → 项目建设 → 资金筹划 → 组织保障 → 分步实施

### 怎么练出框架能力？

1. **积累：建自己的"框架库"** — 把写过的方案、报告、总结分类整理。每一个框架为什么有效？能不能迁移到下一个材料里？
2. **提炼：从具体工作中抽象规律** — 不要只埋头写，要抬头思考。这个工作的核心矛盾是什么？解决的路径是什么？有没有普遍性？
3. **复盘：写完材料回头看** — 这个框架为什么有效？下次还能怎么优化？有没有更好的排列组合？

### 提纲定级原则

- 提纲定到三级，便能胸有成竹
- 新手可细化至四五级，做到腹中有稿
- 起草前切忌匆忙下笔、堆砌资料、平均用力——花时间打磨框架，是最值得的投资

## 费曼十二问：深度思考的追问框架

当面对一个选题觉得"没什么可写"或"写了也很浅"时，用这 12 个层层递进的问题来解剖主题。不需要每条都形成文字，在脑中过一遍，思路就会清晰很多。

### 十二问清单

**第 1 问：前提是什么？** — 这件事成立的基础条件是什么？有哪些事实、现象或背景已经存在？

**第 2 问：目标是什么？** — 写这篇文章的目的是什么？想骂醒读者？教方法？还是纯粹分析现象？目标决定整篇的走向。

**第 3 问：常规做法是什么？** — 普通人遇到这个问题通常会怎么做？先理解"常规"，才能对比出"非常规"的价值。

**第 4 问：高手怎么做？** — 常规方法失效时，厉害的人会怎么处理？这一步逼你思考真正有效的方法是什么。

**第 5 问：核心是什么？** — 这件事最关键的点是什么？打蛇打七寸，找到核心才能避免跑题。

**第 6 问：本质是什么？** — 剥掉所有表象，最底层的东西是什么？核心是"最关键的问题点"，本质要挖到人性规律、社会规则、底层逻辑层面。

**第 7 问：看清本质与看不清本质的人，有什么区别？** — 看透底层规律的人，和蒙在鼓里的人，行为上有什么不同？这个对比能让你的论证更有说服力。

**第 8 问：如何检测完成情况？** — 怎么知道进步了、改善了？要有具体可量化的标准，不能凭感觉。

**第 9 问：可能在哪些方面犯错？** — 按你的方法做，可能踩哪些坑？预判读者的疑虑，反而能建立信任。

**第 10 问：这件事能提升什么能力？** — 按你的方法做，读者能获得什么可迁移的能力？这决定了文章的长期价值。

**第 11 问：值得长期投入吗？** — 这件事的长期价值是什么？如果回答不了，可能选题本身价值有限。

**第 12 问：我有什么亲身经验？** — 你自己试过吗？效果如何？有亲身经历的文章，天然比纯理论更有说服力。如果确实没有相关经历，至少代入思考一遍。

### 使用方式

- **写观点文/分析报告**：12 问全过一遍，确保思考深度
- **写工作总结/汇报**：重点用第 1、2、5、6 问——前提（今年什么背景）、目标（这份总结要达到什么效果）、核心（最重要的工作是什么）、本质（这几件事背后反映了什么规律）
- **写讲话稿**：重点用第 2、4、9、12 问——目标（听众听完应该产生什么反应）、高手怎么做（有没有可借鉴的做法）、可能在哪些方面犯错（预判听众疑虑）、亲身经验（有没有故事可以讲）

### 本质

费曼十二问不是冰冷的框架，而是帮你把思考从"浮在表面"推到"触达底层"的追问系统。它的核心理念和本 skill 一脉相承：**先研究事，再琢磨字**。十二问帮你把事研究透，字自己会出来。
